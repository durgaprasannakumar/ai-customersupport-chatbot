# MVP Implementation Plan — AI Customer Support Assistant

## Phase 1 — Foundation (Weeks 1–2)
- Clean and index Kaggle dataset.
- Build retrieval pipeline (FAISS + embeddings).
- Create baseline Streamlit UI.

## Phase 2 — Integration (Weeks 3–4)
- Connect GPT-4 / Claude model.
- Add brand filter, feedback logging, latency tracking.

## Phase 3 — Evaluation (Weeks 5–6)
- Create evaluation notebook to score grounded accuracy.
- Analyze latency & cost trade-offs.
- Prepare outputs/screenshots for portfolio.

## Phase 4 — Business Packaging (Weeks 7–8)
- Build background research deck.
- Add market research, ideation, and prioritization docs.
- Publish on GitHub Pages or Notion portfolio.
